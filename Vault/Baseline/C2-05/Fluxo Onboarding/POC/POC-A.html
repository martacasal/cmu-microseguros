Um passo, um ecrã

The classic guided wizard: each screen asks one thing, with big tactile controls and one primary button. First impression: show the product working. Welcome shows the real "in activity" screen, and each value screen has a small demo the user can try (turn protection on, include the bike), so they understand the app before they create an account. The account screen says what the account gives them, and a "Conta criada" screen marks the moment and explains what comes next.

How it follows the spectrum

  • Guided 5/0: one path, Back + progress 1–12 on every question; no menus, no jumping.
  • Proactive 3/2: quiet hint cards built from earlier answers ("Because you run…"), never pop-ups.
  • Minimal 4/1: one question per screen; detail in "Why?" accordions and bottom sheets.
  • Direct 3/2: tap chips and segments; free text only for name and "+ outra".
  • Step control 4/1: the user answers every step; one review at "O teu perfil".
  • On-commit 5/0: nothing is checked while typing; errors appear only after Continue, confirmations as toasts.
