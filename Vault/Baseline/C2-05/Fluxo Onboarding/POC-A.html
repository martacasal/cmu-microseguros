Uma pergunta de cada vez

A classic guided wizard. The homepage is split into three single questions (activity, duration, equipment), each on its own screen with one big answer area. Familiar form controls: radio list, slider, yes/no cards.

Behaviour

  • Guided 5/0: one path, progress bar, back arrow only.
  • Proactive 3/2: smart default duration with a reason; a calm "5 min left" nudge.
  • Minimal 3/2: price first, reasons in expandable rows.
  • Direct 4/1: tap and slide; no typing.
  • Step control 3/2: user confirms each answer; system only suggests.
  • Staged 4/1: price only after Começar; extend and stop need a confirm.
