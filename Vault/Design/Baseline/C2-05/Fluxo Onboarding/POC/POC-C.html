POC C

Capítulos com revisão

First impression: the user's own Pulse card. On Welcome the user sees an empty card, and each value screen highlights one row of it (price, cover, equipment). The account is the first thing written on the card, and every chapter save fills in more of it, until "O teu perfil" shows it complete. The card is the object the user builds and keeps. The 12 questions are grouped into 3 chapters: Sobre ti, O teu desporto, Proteção e acordo. Each chapter opens with a short "what's coming and why" screen, then the questions one by one, then a review where the user checks their answers, changes any row and saves. Only saved chapters get a tick, so progress grows with each save.

How it follows the spectrum

  • Guided 5/0: fixed chapter order; "Alterar" in a review opens just that one question and then returns to the review. There is no free jumping.
  • Proactive 3/2: chapter openers say what's next and how long it takes; the reviews summarise answers on their own.
  • Minimal 4/1: one question per screen; the review is the only denser view, and it is short.
  • Direct 3/2: chips, segments and checkboxes; free text only for name and "+ outra".
  • Step control 4/1 + review 1: the user answers every step; the system-built summary is the "approve" moment.
  • On-commit 5/0: nothing counts until "Está certo, guardar"; each save shows a toast and ticks the chapter.
